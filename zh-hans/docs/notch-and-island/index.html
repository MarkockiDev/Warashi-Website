Warashi 的刘海只显示此刻正在进行的事。没有事情时，刘海就只是刘海。当智能体在工作、休息即将到来、保持唤醒已开启、电池正充电到你设定的上限、网速测试正在运行或背景模糊已开启时，其中最重要的一项会显示在刘海左侧，下一项显示在刘海右侧，各自带有在“工具”中设定的符号和颜色。右侧那一项上的小数字表示还有多少项。

在没有刘海的显示器上（例如外接显示器），一个黑色的小岛会在刘海原本所在的位置起同样的作用。没有事情进行时，它会退到一旁。

有事需要你处理时

开启刘海或小岛后，Warashi 会从那里告诉你消息，而不是在屏幕角落弹出通知。刘海会自动展开，用简单的话说明发生了什么，边缘以该通知的颜色亮起，几秒钟后收起。之后，这条通知会以符号的形式等在刘海旁，排在所有其他内容之前，直到你处理它、关闭它，或者它不再成立。

通知你可以在刘海中做什么
提醒，例如你的 Mac 温度偏高或Chrome 占用了大量 CPU了解更多会打开解释它的页面；占用大量 CPU 或内存的 App 可以当场退出，卡住的编译器也可以当场停止
你的 Mac 内存不足值得退出的 App，从大到小排列，每个都带有退出，另有全部退出
废纸篓越来越大清倒废纸篓…，会先清楚地问你一次
智能体已完成或需要你打开它的 App。刘海会一直展开，直到你回到该 App
接近限额的智能体何时重置

每条通知都有一个小小的×，可将其关闭。没有刘海或小岛时，提醒会以通知的形式送达，内存卡片和废纸篓卡片则像以前一样从 Warashi 的菜单栏项目下方弹出。

打开它

  1. 将指针停在刘海上

    将指针在刘海（或小岛所在位置）上停留片刻，它就会向下展开：每个时刻占一行并带有其控制项，下方还有一行显示你的 Mac 状态（CPU、内存、电池）。没有事情进行时，它会提供保持唤醒、休息和立即充满电。

  2. 移开指针即可收起

    移开指针，它就会收起。点按它，或点按角落里的打开 Warashi，即可打开窗口。

选择外观

在“设置 › 自定 › 始终显示”中：在刘海旁显示正在进行的事和无刘海显示器上的小岛可分别将它们完全关闭。无事时显示读数会在安静的刘海旁显示你选择的两个数字，除非你另选，否则为 CPU 和内存。请参阅自定。

与其他刘海应用一起使用

其他应用也可能使用刘海，而且各自独立监视指针，所以指向刘海可能会同时打开两者。Warashi 的刘海保持在最上层并响应指针。“设置” › “自定” › “始终显示”会列出其他使用刘海的应用；若只想看到 Warashi，请在那个应用中关闭刘海功能。Warashi 从不更改其他应用。

补充说明：不确定某条通知是什么意思？每条通知都有了解更多，会打开 Warashi 中解释它的页面，并显示你还能做的其他操作。

如果出现问题

  • 小岛挡住了外接显示器上的内容：在设置 › 自定 › 始终显示中关闭无刘海显示器上的小岛。
  • 保持唤醒自己开启了：把指针指向刘海即可查看原因。智能体工作时表示“设置 › 编程智能体”中的这条规则已开启。
