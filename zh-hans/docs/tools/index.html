工具（⌘5）是一个工具箱，收纳了你偶尔需要的小功能。每项都只在你要求时运行。

工具作用
休息显示下次休息的时间，休息一下会立即开始一次休息。点按卡片可设置你的节奏。见休息。
保持唤醒开始让你的 Mac 保持唤醒一段时间、直到任务完成，或在某个 App 打开期间保持唤醒。见保持唤醒。
网速你最近一次的下载和上传速度。打开会前往网速测试。
磁盘速度测试会在大约六秒内测出你的磁盘读写速度。连接了外置磁盘时，可以选择测试哪一个。
Wi-Fi你的 Wi-Fi 信号此刻有多好，从“极佳”到“较差”，并显示信号、噪声、信道、频段和链接速率。
充电上限充电上限，只在有电池的 Mac 上显示。点按卡片（滑块和开关以外的地方）即可打开电池。
清洁屏幕开始会让所有显示器变黑，灰尘和污渍就会显现。切换为白色、红色、绿色或蓝色，可以找出坏点。按 Esc 结束。
清洁键盘开始会调暗屏幕，并在你擦拭时关闭所有按键，同时统计它拦下的按键次数。按住 Esc 两秒，或按住按住以结束，即可结束。
外置磁盘已连接的数量。全部推出会推出每一个；如果 macOS 因某个磁盘正在使用而拒绝，它会告诉你是哪一个。
废纸篓废纸篓里有多少内容，在“工具”打开期间保持更新。打开会在 Finder 中显示它；如要清倒，请使用储存空间中的“废纸篓”卡片。
Mac 报告拷贝会把一份简短摘要放到剪贴板，方便粘贴到客服对话中：Mac 型号和芯片、macOS、上次重新启动、内存、CPU、温度、磁盘和 SSD 寿命、电池健康度和循环次数，以及 Warashi 版本。不含个人信息：没有姓名、App、路径、序列号或历史记录。

按下任意图块上的星标，让它始终排在第一。

关于磁盘速度测试

它会写入一个测试文件约三秒钟，再读回约三秒钟，绕过缓存，让你看到磁盘的真实速度。文件会立即删除，不留下任何东西。磁盘至少需要 9 GB 可用空间。只保留你最近一次的结果。

关于清洁屏幕和清洁键盘

两者都会覆盖所有显示器，并在运行期间关闭 ⌘Tab、强制退出和程序坞，无需任何权限。音量、亮度和媒体键、Touch ID 以及电源按钮仍然可以传到 macOS。每项都会在两分钟后自动结束，或在你的 Mac 睡眠或锁定时结束。你也可以在菜单栏窗口的⋯菜单和“查找任何内容”中找到它们。

关于 Wi-Fi

只在工具打开时，每两秒读取一次 Wi-Fi。Warashi 不显示你的网络名称，因此从不需要定位权限。

补充说明：查找任何内容（⌘K）可以在任何地方运行大多数工具：试试“休息”“唤醒”“清洁”“报告”或“废纸篓”。
