菜单栏窗口和展开的刘海都可以由你来排列。两者使用同一个编辑器：左侧是实时的真实界面，右侧是你的选项。每项更改都会立即生效，无需存储。

  1. 打开编辑器

    对于菜单栏窗口，点按其底部的滑块按钮，或前往设置 › 菜单栏。对于刘海，点按展开的刘海中的滑块按钮，或前往设置 › 刘海。

  2. 添加或移除

    在已显示下，按 − 可移除某项。在更多下，按 + 可添加它；它会加到已显示内容的末尾。被隐藏的读数仍会记录在历史记录中。

  3. 拖移到你想要的位置

    将指针移到预览中的任意内容上并拿起它。它会随指针浮起，原位置留有一圈淡淡的轮廓，移动时其他内容会向旁边让开。松开即可放下。列表中的行也以同样方式移动。

  4. 对刘海也这样设置

    设置 › 刘海会把刘海显示两次：收起时的样子，以及指针移到上方时的样子。展开的刘海中的任何内容都可以拿起并移动。

  5. 更改刘海旁的两个数字

    点按收起的刘海中的任一数字，即可选择该侧显示的内容。两个数字之间的箭头可互换两侧。

  6. 重新开始

    只要有内容与默认设置不同，就会出现重置，点按即可恢复全部默认设置。

刘海如何自动排布

两者都会自动排布，始终保持整齐。

菜单栏窗口

菜单栏窗口只有一个最大尺寸，且不会滚动，因此始终能放进你的屏幕。列表上方的小条显示已用了多少空间。没有空位时，+ 会变暗：请先移除一些项目。网速测试、电力流向和已连接设备默认放在更多下，随时可以换入。

CPU 和内存带有图表，因此各占两项其他读数的高度，较矮的读数会填满它们旁边的空间。如果高项旁边只有一项矮读数，高项会去掉图表，避免出现空白。

展开的刘海

它最多可容纳六项读数，外加 App 排行和已连接设备。列表会显示你已用了多少，位置用完时 + 会变暗。读数始终均匀排列，因此不会有哪一项单独占一行：

读数排布方式
1、2 或 3一行
4两行，每行两项
5先三项，再两项
6两行，每行三项
补充说明：其他显示器上的小岛与刘海显示相同的内容。使用旁白（VoiceOver）？列表中的每一行都有“上移”和“下移”操作。

如果出现问题

  • 某项读数没有显示：电池和电力流向只在带电池的 Mac 上出现，“已连接”只在有设备连接时出现。网速测试和电力流向只在菜单栏窗口中提供，刘海中没有。
  • 收起的刘海中某项读数显示为短横线：几秒钟内就会显示出来。如果一直如此，说明 macOS 在你的 Mac 上不提供该读数。
