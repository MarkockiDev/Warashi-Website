macOS 不允许普通 App 读取 WindowServer、kernel_task 或 mds 等系统进程。可选的辅助程序可让 Warashi 包含这些进程。

  1. 打开设置 › 系统

    按下 ⌘,，然后选择系统标签页。

  2. 开启“显示系统进程”

    Warashi 会安装一个小型辅助程序。随后 macOS 会请你批准。

  3. 在系统设置中批准

    在 Warashi 中点按打开登录项设置，或打开系统设置 › 通用 › 登录项。在允许在后台下开启 Warashi。macOS 可能会请你输入密码。

  4. 确认已生效

    回到 Warashi，系统进程现在会出现在 App、App 排行和历史记录中。

辅助程序能做什么、不能做什么

  • 它只能读取进程计数器：CPU 时间、内存、磁盘和能耗。
  • 它不接受任何命令、路径或参数，且只响应 Warashi（双方会互相验证对方的签名）。
  • 关闭该开关即可将其移除。

如果出现问题

  • 仍然没有系统进程：请检查系统设置 › 通用 › 登录项 › 允许在后台中 Warashi 是否已开启，然后将该开关关闭再重新开启。
