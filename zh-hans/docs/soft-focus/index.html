背景模糊让屏幕安静下来。除你正在使用的窗口外，其余窗口都会柔化为模糊，只有你的工作保持清晰。点按另一个窗口，它就会变清晰。

  1. 开启它

    在“工具”中的“背景模糊”卡片上按开启，或点按卡片打开其页面并使用顶部的开关。也可以用 ⌘K 找到它。

  2. 晃动或按快捷键

    首次开启后，在任何应用中按 ⌃⌥⌘F 即可开启或关闭。在“背景模糊”页面上打开晃动指针，即可通过快速左右晃动做到同样的事；按住 ⇧ 并晃动，可在松开前查看全部内容。

  3. 照常工作

    点按任一模糊的窗口，它就会变清晰。移动窗口或调整大小时，清晰区域会跟随。菜单、程序坞和菜单栏始终保持清晰。

设置

  • 模式：柔和只轻轻柔化，深度会模糊并调暗其余一切。
  • 色调在模糊上叠加一种颜色：暮色、陶土、靛蓝或无。颗粒会添加细腻的胶片颗粒。
  • 应用的所有窗口会让前台应用的所有窗口都保持清晰，例如文档及其检查器。
  • 仅限你正在使用的显示器会让其他显示器保持原样。
  • 从不模糊的应用列出背景模糊会让开的应用：其中任一应用在最前面时，不会模糊任何内容。
  • 晃动指针在你打开前一直关闭：指针移动时，监视指针会消耗少量电量。灵敏度决定晃动需要多大幅度。键盘快捷键 ⌃⌥⌘F可以关闭。
须知：背景模糊无需任何权限。Warashi 从不查看屏幕内容：模糊由 macOS 完成，Warashi 只知道你正在使用的窗口在哪里。Mac 屏幕进入睡眠时它会关闭，Warashi 打开时它默认关闭。

如果出现问题

  • 某个窗口短暂地错误保持清晰：用键盘切换窗口后，清晰区域会在半秒内跟上。
  • 晃动没有反应：在“背景模糊”页面上打开晃动指针，然后试着晃得更快，或提高灵敏度。
