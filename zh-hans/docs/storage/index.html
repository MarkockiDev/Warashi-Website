“储存空间”是健康度中的一个标签页。它显示是什么占用了启动磁盘。它会以上次的结果打开，并在结果超过六小时时更新。你移除的任何东西都会在确认后移到废纸篓，在清倒之前都可以放回。

  1. 打开储存空间

    选择健康度，然后选择储存空间；也可以按下“现在”或菜单栏窗口中的磁盘图块，或体检储存空间卡片上的打开。

  2. 开启完全磁盘访问权限

    如果你没有在欢迎导览中完成这一步，会有一张卡片提供此选项。点按打开系统设置，并在列表中开启 Warashi，只需一次。这样储存空间就能统计桌面、文稿、下载、照片和 App 数据。Warashi 只读取大小，从不读取你的文件，且不会有任何内容离开你的 Mac。你也可以跳过这一步：储存空间会测量其余部分，macOS 也不会来打扰你。

  3. 探索圆环图

    内圈是你的各个类别，外加“系统”和“可用”。外圈是各类别中最大的文件夹。将指针移到任一部分上可查看其名称和大小；其余部分会变暗，列表中对应的行会亮起。

  4. 查看内部内容

    选择一个类别可查看其中最大的项目。文件夹旁的箭头会进入该文件夹并测量其中的一切，你可以一层层往下看。放大镜会在“访达”中显示项目。你自己的文件还有废纸篓按钮。

  5. 随时重新扫描

    随时可以按下重新扫描。扫描时你可以离开页面。储存空间会在你打开它且上次扫描已超过一天时自动重新扫描，但使用电池或处于低电量模式时从不自动扫描：一次扫描要读取大量磁盘内容，所以除非你主动要求，它会等到接上充电器。

  6. 清倒废纸篓

    在圆环下方，废纸篓卡片会显示废纸篓中有多少内容和多少个项目，包括已连接磁盘上的废纸篓。它会在你打开页面时检查，并在页面保持打开期间每两分钟检查一次。清倒废纸篓…会先询问你，说明将清除多少内容，然后彻底删除，并在过程中显示计数。正在使用的内容会保留，卡片也会说明这一点。

其他标签页

  • 大文件：超过 100 MB 的文件，按大小或新旧排序。
  • 下载：“下载”文件夹里的所有内容，从旧到新，并标出安装器：App 装好后通常就用不上了。需要完全磁盘访问权限。
  • App：你安装的所有 App，3 个月未打开的排在前面。移除…会列出 App 及其在资源库中留下的东西（App 数据、缓存、设置、已存储的窗口、日志，以及有完全磁盘访问权限时的沙盒数据），每项附大小和勾选框，并把勾选的移到废纸篓。请先退出该 App。如果 macOS 拒绝，请在“系统设置”的App 管理中允许 Warashi。Apple 自己的 App 不会列出。最后，已移除的 App 留下的东西会按标识符列出你已删除的 App 在资源库中留下的、至少一个月未改动的内容。仍有 App 安装着的开发者的内容、共享数据和 Apple 自己的内容都不会列出。
  • AI 模型：Ollama、LM Studio 和 Hugging Face 的模型及其大小。LM Studio 和 Hugging Face 的模型可以移到废纸篓。Ollama 在模型之间共享文件，因此拷贝命令会给出它自己的 ollama rm，在“终端”中运行。

各类别的含义

  • 开发者：Xcode 数据和模拟器。
  • App 数据：你的资源库文件夹中除“开发者”之外的所有内容。
  • 废纸篓：等待清倒的内容。
  • 其他个人文件夹：直接位于你的个人文件夹中的其他内容，例如 Code 文件夹。
  • 系统及其他：剩余的部分：macOS 本身、快照，以及 Warashi 无法读取的位置。
补充说明：文件夹大小可能略有重叠，因为在磁盘上共享空间的文件会在每个位置各计一次。查看和清倒废纸篓需要完全磁盘访问权限；没有它时，该卡片会提供打开系统设置的选项。

如果出现问题

  • 某些位置需要完全磁盘访问权限：点按列表中的那一行，然后点按打开系统设置。如果列表中没有 Warashi，请把它的图标拖进去。如果仍未被统计，请点按重新打开 Warashi。
