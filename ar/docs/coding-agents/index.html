الأدلة

أبقِ الـ Mac مستيقظًا والغطاء مغلقأوقف شحن MacBook عند 80%أزل التطبيقات من الـ Mac بالكامللماذا الـ Mac بطيءكم من ذاكرة الوصول العشوائي أحتاج في الـ Macما الذي يستنزف بطارية MacBookما الذي يشغل المساحة على الـ Macاختبر سرعة إنترنتك على الـ Mac

إن كنت تعمل مع Claude Code أو Codex أو Cursor، يستطيع Warashi مراقبتها عنك: ما تفعله كل جلسة، وكم اقتربت من حد استخدامها، ومتى تحتاج إليك. وهو متوقف حتى تشغّله.

  1. شغّله

    افتح الإعدادات › وكلاء البرمجة وشغّل مراقبة Claude Code وCodex وCursor، أو اضغط تشغيل… في بطاقة وكلاء البرمجة أعلى التطبيقات › المطوّر. يسأل Warashi مرة واحدة هل يستطيع إرسال الإشعارات.

  2. اختر ما تريد أن تُبلَّغ به

    أخبرني حين يحتاج وكيل إليّ (توقف ليطلب إذنًا أو جوابًا)، وأخبرني حين ينتهي وكيل (بعد دقيقة أو أكثر من العمل) وحذّرني قرب حد الاستخدام (عند 80% و95%). يصل كل منها كإشعار ويفتح النتوء: الحد لبضع ثوانٍ، والباقي حتى تعود إلى تطبيق الوكيل. انقر على الإشعار لترى وكلاءك.

  3. شاهدها وهي تعمل

    تعرض بطاقة وكلاء البرمجة في التطبيقات › المطوّر كل جلسة: تعمل أو تحتاج إليك أو انتهت، وفي أي مشروع. وأثناء عمل أحدها، يعرض النتوء المدة بجانبه، ويأتي الوكيل المنتظِر أولًا. أضف وكلاء البرمجة إلى نافذة شريط القوائم في الإعدادات › التخصيص لترى الحدود هناك أيضًا، أو اختر حدّ وكيل البرمجة بجانب الروح في شريط القوائم.

حدود الاستخدام

كل حد حلقة: حد الخمس ساعات والحد الأسبوعي، مع موعد إعادة الضبط. تتحول الحلقة إلى الكهرماني من 80% وإلى الأحمر من 95%.

  • Codex يكتب حدوده في ملفاته على الـ Mac، لذا تظهر بعد إجابة Codex التالية.
  • Cursor يعرض استخدامه الشهري. شغّل إظهار استخدام Cursor؛ يسأل Warashi شركة Cursor عنه بتسجيل الدخول الذي يحتفظ به وكيل Cursor لسطر الأوامر في سلسلة المفاتيح، لذا سجّل الدخول مرة واحدة بـ cursor-agent login. إذا سألك macOS، اختر السماح دائمًا.
  • Claude Code لا يحتفظ بحدّه على الـ Mac. شغّل إظهار حد استخدام Claude فيسأل Warashi شركة Anthropic عنه، كل بضع دقائق أثناء عمل Claude Code، مستخدمًا تسجيل الدخول الخاص بـ Claude Code من سلسلة المفاتيح. يسألك macOS مرة واحدة، عند التشغيل، إن كان يجوز لـ Warashi قراءته: اختر السماح دائمًا. لا يسأل Warashi من تلقاء نفسه: إذا احتاج macOS إلى موافقتك لاحقًا، تخبرك الإعدادات بذلك مع زر السماح…. يُستخدم تسجيل الدخول لهذا الطلب فقط؛ ولا يُخزَّن ولا يُغيَّر ولا يُرسَل إلى أي جهة أخرى.

تسجيل الدخول إلى Claude

تحت إظهار حد استخدام Claude، تعرض الإعدادات الحساب الذي سجّل به Claude Code الدخول. لم تسجّل الدخول؟ يفتح تسجيل الدخول شاشة تسجيل الدخول الخاصة بـ Claude Code في الطرفية، وتنقلك إلى متصفحك. يجدّد Claude Code تسجيل دخوله فقط أثناء استخدامك له، لذا بعد يوم هادئ قد يتوقف الحد عن التحديث: ومع تفعيل تجديد تسجيل الدخول تلقائيًا، يطلب Warashi من Claude Code إجابة صغيرة واحدة من أصغر نماذجه، مرة كل ست ساعات على الأكثر، فيجدّد Claude Code تسجيل الدخول. وجدّد الآن يفعل ذلك فورًا. لا يجدّد Warashi تسجيل الدخول ولا يكتبه بنفسه أبدًا.

ابقَ مستيقظًا أثناء عملهم

فعّل أبقِ جهاز Mac مستيقظًا أثناء عمل وكيل في الإعدادات › وكلاء البرمجة. يبقى جهاز Mac مستيقظًا ما دام وكيل يعمل أو ينتظرك، وثلاث دقائق بعد ذلك. وهذا منفصل عن إبقاء الجهاز مستيقظًا الذي يبقى متوقفًا: يبقى الـ Mac وحده مستيقظًا، وتنام الشاشة كالمعتاد. ومع تفعيل البقاء مستيقظًا مع إغلاق الغطاء، يواصل MacBook الموصول بالشاحن عمله والغطاء مغلق.

في سجل الرحلة

العمل لأكثر من دقيقتين يُكتب في سجل الرحلة: «عمل Claude Code لمدة 1 س 12 د، في shop».

مفيد أن تعرف: يقرأ Warashi فقط حالة كل جلسة وحدودها من ملفات الوكلاء نفسها. وليس شيفرتك ولا أوامرك ولا محادثاتك أبدًا، ويُعرض اسم مجلد المشروع فقط. ولا تتضمن التحليلات أيًّا من الاثنين.

إن كان هناك ما ليس على ما يرام

  • يقول حد Claude إن تسجيل الدخول انتهت صلاحيته: شغّل Claude Code مرة واحدة في Terminal فيجدّد تسجيل دخوله. أما Claude Code داخل تطبيق Claude لسطح المكتب فيحتفظ بتسجيل دخوله في مكان آخر.
  • حد Codex لا يظهر: يظهر بعد إجابة Codex التالية، من جلسات آخر أسبوع.
  • Cursor لا يقول أبدًا إنه يحتاج إليك: لا يسجّل Cursor ذلك في أي مكان يجوز لـ Warashi قراءته، لذا تظهر له حالتا «يعمل» و«انتهى» فقط، بعد نحو دقيقة من توقفه.
  • وكلاء آخرون: يعرض Gemini CLI وAider وغيرهما استخدام المعالج والذاكرة في المطوّر، دون حالة عمل أو انتظار.
