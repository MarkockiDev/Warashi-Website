How much RAM do I need on a Mac?

Read memory pressure and swap like a pro, and size the memory of your next Mac from your own usage.

5 min read · Updated 3 November 2026

“How much RAM do I need?” is the most common question before buying a Mac, and the most guessed. The honest answer is: as much as your memory pressure says, not what “Memory Used” says.

Why “Memory Used” misleads

macOS treats unused memory as wasted memory. It fills it with file caches and keeps apps' memory compressed instead of throwing it away. So a Mac showing 15 of 16 GB “used” can be perfectly happy.

What to look at instead

  • Memory pressure: green, yellow or red in Activity Monitor's Memory tab. This is macOS telling you how hard it's working to find memory.
  • Swap used: memory written out to the disk. A little is normal; gigabytes of it every day means you're short.
  • Compressed: memory squeezed to fit. High compression with pressure rising means you're near the edge.

Rules of thumb

What you see over a typical weekWhat it means
Pressure green, swap near zeroYou have enough. More memory won't make it faster.
Yellow on busy days, some swapYou're at the limit. The next Mac should have one size more.
Yellow or red most days, swap in gigabytesYou're short. One or two sizes more.

Measure, don't guess
