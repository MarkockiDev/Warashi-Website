Warashi zit in een gratis openbare bèta: elke versie genummerd 0.x. Bedankt dat je het al vroeg probeert.

Tijdens de bèta

  • Alles is ontgrendeld en gratis, op zoveel Macs als je wilt.
  • Updates komen automatisch binnen, dus je hebt altijd de nieuwste bèta.
  • Instellingen › Licentie toont Ontgrendeld (voorlopige versie).

Als Warashi 1.0 komt

  1. De bèta stopt

    Als 1.0 uitkomt (en uiterlijk op 1 maart 2027) stopt de bèta met meten. Het menubalkvenster en het venster tonen De bèta is afgelopen.

  2. Werk bij naar 1.0

    Klik op Update naar Warashi 1.0. Warashi 1.0 is een eenmalige aankoop, zonder abonnement, voor maximaal twee Macs.

  3. Voer je licentie in

    Voer na je aankoop je licentiesleutel in bij Instellingen › Licentie. Je geschiedenis uit de bèta staat er nog.

Goed om te weten: Je geschiedenis wordt nooit gewist als de bèta eindigt: ze blijft op je Mac, klaar voor 1.0.
