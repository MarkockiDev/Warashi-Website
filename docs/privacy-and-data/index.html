Warashi is built so that your Mac's story stays on your Mac.

What stays on your Mac

  • All measurements and history, in a small database in your user Library (Application Support › Warashi).
  • App and process names, paths, command lines and signatures.
  • Activity records (if you turn activity recording on), alerts and the Flight Log.
  • Anything written by Apple Intelligence: it runs on your Mac, with Apple's on-device model.

Warashi never asks for Screen Recording, Input Monitoring or Location, and never reads window titles, websites, file contents or keystrokes. Breaks only check, at the moment one is due, whether your microphone or camera is in use, and record nothing. Full Disk Access is optional and used only to add up sizes for Storage.

If you connect an AI app

This is optional and off until you set it up. An AI app you connect, and its service, can read app names and usage history when it asks. It never receives activity records or file paths, and none of it goes to us. See Command line & AI apps.

Usage statistics, exactly

A random install ID (not tied to you), the Warashi version, the macOS version, the chip family (for example “M5”), the language, and named events such as “app launched”, “window opened”, “History viewed”, a setting and its new value, or the kind of alert that fired. It never includes app or process names, file paths, history, activity records, licence keys, names, emails or IP addresses. It's listed in the welcome tour and Settings › General.

Export your data

Settings › General › Privacy › Export as CSV… writes everything recorded to a dated folder of CSV files you choose.

Delete your data

  1. Delete activity only

    Settings › Activity › Delete All Activity Data…

  2. Delete everything

    Quit Warashi (⋯ › Quit Warashi in the menu bar window), then in Finder choose Go › Go to Folder…, enter ~/Library/Application Support/Warashi and move that folder to the Bin.
