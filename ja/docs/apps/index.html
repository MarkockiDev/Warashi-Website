アプリには、各アプリが現在かけているコストが、ヘルパーをまとめた形で表示されます（Chromeは20行ではなく1行です）。

  1. アプリを開く

    サイドバーのアプリを選ぶか、⌘2を押します。負荷の大きい上位4つのアプリが、直近1分のグラフ付きのカードとして最上部に並びます。順位がはっきり変わったときだけ入れ替わります。

  2. 検索または並べ替え

    アプリとプロセスを検索に入力すると、名前でアプリやプロセスを探せます。CPU、メモリ、エネルギー、ディスクでリストを並べ替えられます。

  3. アプリのドロワーを開く

    アプリをクリックすると、ドロワーにCPU、メモリ、エネルギー、実行中のすべてのプロセス、署名者（Apple、デベロッパのチーム、アドホック）、Hardened Runtimeを使用しているかどうか、ディスク上の場所が表示されます。

    終了…は通常の方法でアプリに終了を要求するので、作業内容を保存できます。Finderに表示でそのアプリの場所を開きます。バッテリー使用中は、終了した場合にどれくらい長持ちするかの目安も1行で表示されます。

  4. 1つのプロセスを調べる

    ドロワーでプロセスをクリックすると、その起動方法（コマンドライン、親プロセス、ユーザ、開始日時、起動ジョブ）を確認できます。escキーを押すか外側をクリックすると、ドロワーが閉じます。

補足： サブタイトルには、負荷の高い（CPU 10%以上の）アプリの数が表示されます。WindowServerなどのシステムプロセスは、オプションのヘルパーをオンにすると表示されます。システムプロセスをご覧ください。
