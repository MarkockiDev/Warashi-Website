ガイド

Macが遅い原因Macに必要なRAM容量MacBookのバッテリーを消耗させているものMacのストレージを占めているものMacでインターネット速度をテストする

アラートは、対応が必要なときにお知らせします。問題ごとに1回だけで、続いている間ずっと通知することはありません。

  1. 設定 › アラートを開く

    ⌘,を押してアラートを選びます。

  2. 必要なアラートをオンにする

    各スイッチが1つのルールです（下の表を参照）。オンにするまで、すべてオフです。

  3. 通知を許可

    初回は、Warashiに通知の送信を許可するかをmacOSがたずねます。許可をクリックしてください。許可しなかった場合も、アラートはWarashiとノッチに表示され、設定に通知設定を開くが表示されます。

  4. アラートを確認・ミュートする

    履歴を選び、アラートタブを開くと、過去30日間のアラートが根拠とともに表示されます。ミュートをクリックすると、そのアプリについてのアラートを止められます。

パブリックIPのアラート

このアラートがオンのあいだだけ、WarashiはCloudflareの1.1.1.1に、10分ごとと、ネットワークが変わった直後に、パブリックIPv4アドレスを問い合わせます。リクエストには、あなたやMacについての情報は含まれません。アドレスが変わると新しいアドレスをお知らせし、VPNを確認するよう促します。アラートをオフにすると、Warashiは問い合わせをやめ、アドレスを忘れます。

補足： Warashiは1分に1回チェックします。同じアラートは、原因が解消してから1時間（メモリは6時間）たつまで繰り返されません。アラートが作動すると、ノッチまたはアイランドが数秒間開いて理由を表示し、フライトログにも記録されます。

うまくいかないときは

  • 通知が届かない場合： システム設定 › 通知 › Warashi を確認してください。通知がオフの場合、Warashiは設定 › アラートにその旨を表示します。

詳しくはトラブルシューティングをご覧いただくか、adam@warashi.appまでメールでお問い合わせください。
