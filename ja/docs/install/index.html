インストールは約1分で終わります。Apple silicon（M1以降）のMacと、macOS 26以降が必要です。ご不明な場合は、Appleメニュー › このMacについてを選ぶと、チップとmacOSのバージョンを確認できます。

  1. Warashiをダウンロードする

    warashi.appのどのページでも、上部のダウンロードをクリックします。ブラウザがWarashi.dmgを、通常はダウンロードフォルダに保存します。サイズは約15 MBです。

  2. ディスクイメージを開く

    ダウンロードフォルダのWarashi.dmgをダブルクリックします（ブラウザのダウンロード一覧からクリックしても開けます）。WarashiとApplicationsフォルダのあるウインドウが開きます。

  3. Warashiをアプリケーションにドラッグする

    Warashiアイコンをアプリケーションフォルダにドラッグします。コピーが終わったら、ウインドウを閉じてディスクイメージを取り出せます（Finderのサイドバーの「Warashi」の横にある⏏ボタン）。

  4. Warashiを開く

    アプリケーションフォルダを開いて、Warashiをダブルクリックします。インターネットからダウンロードしたため、macOSが開いてよいかを一度確認します。Warashiは署名されていて、Appleによる確認を受けているので、開くをクリックしてください。

  5. ようこそツアーを見る

    ようこそツアーが開きます。全6ページです。各ページの内容はようこそツアーをご覧ください。

  6. メニューバーでわらしを見つける

    Warashiは画面右上のメニューバーにいます。小さなわらしと、その横にリアルタイムの数字がひとつ。いつでもクリックしてください。

補足： Warashiはバックグラウンドで動作中、Dockにアイコンを表示しません。ウインドウを開いている間はDockと⌘-Tabに表示されるので、見失うことはありません。

うまくいかないときは

  • 「Warashiは開けません」、またはアプリが壊れていると表示される： warashi.appからもう一度ダウンロードして、新しいコピーを開いてください。Warashiは必ずwarashi.appからダウンロードしてください。
  • お使いのMacが非対応と表示される： WarashiにはApple siliconとmacOS 26が必要です。Intel Macには対応していません。
  • わらしが見えない： メニューバーが混み合っていると、ノッチの裏に隠れることがあります。メニューバーにWarashiが見つからないをご覧ください。

詳しくはトラブルシューティングをご覧いただくか、adam@warashi.appまでメールでお問い合わせください。
