メニューバーとポップオーバー

わらしの横の数字を選び、警告を確認して、そのほかはポップオーバーで使います。

Warashiはメニューバーに小さな項目を1つだけ表示するので、混み合ったメニューバーにも収まります。わらしと、リアルタイムの数字がひとつです。

メニューバーの表示内容を選ぶ

  1. 設定 › メニューバーを開く

    わらしをクリックし、ポップオーバー下部の歯車（または⌘,）を押して、メニューバータブを選びます。

  2. 数字を選ぶ

    わらしの横を使います：CPU（初期設定）、メモリ、GPU、電力、温度、ネットワーク、ディスク、バッテリーから選べます。わらしだけにするにはなしを選びます。上部のプレビューで見た目を確認できます。

  3. 警告の扱いを決める

    対応が必要なことを表示をオンにすると、メモリが不足したりMacが高温になったりしている間、数字が▲付きの問題表示（例：▲ MEM 29 GB）に切り替わり、その後元に戻ります。

ポップオーバーを使う

  1. わらしをクリックする

    ポップオーバーには、すべての測定値が1枚のガラスのような面に表示されます。CPUとメモリは直近1分をグラフで表示し、直近1時間の95パーセンタイル（p95）とピークも表示します。

  2. 接続中のものを確認する

    バッテリーを報告するものや外付けドライブが接続されると、接続済みセクションに、AirPodsやマウスなどのワイヤレスデバイスとその充電残量、ドライブの空き容量と取り出しボタンが表示されます。使用中のドライブはmacOSが取り出しません。

  3. タイルからページを開く

    電力、ネットワーク、ディスクの測定値には小さな矢印があり、押すことができます。ウインドウで電力フロー、スピードテスト、ストレージが開きます。

  4. 電力の行き先を確認する

    エディタで電力フローを追加すると、Macに電力を供給しているものと、その電力の行き先がワット単位で表示されます。押すと電力フローのページ全体が開きます。

  5. 接続をテストする

    エディタでスピードテストを追加し、テストを開始（または再テスト）を押します。速度がその場でリアルタイムに表示されます。ポップオーバーを閉じてもテストは続きます。矢印を押すとスピードテストのページ全体が開きます。

  6. 上位アプリを確認する

    下部に、現在負荷の大きいアプリが表示されます。CPU、メモリ、ディスクを切り替えると、順位が変わります。

  7. さらに進む

    フッターには、ウインドウを開くWarashiを開く（⌘O）、Warashi自身の使用量、表示項目を選ぶスライダーボタン、設定の歯車、終了の電源ボタンがあります。外側をクリックするかescキーを押すと、ポップオーバーが閉じます。

ポップオーバーの表示内容を選ぶ

  1. エディタを開く

    ポップオーバー下部のスライダーボタンをクリックするか、設定 › メニューバーを開きます。左側にポップオーバーそのものがライブで表示されます。

  2. 変更する

    −または+を押して測定値を削除・追加し、ドラッグして移動します。画像付きの詳しい手順はポップオーバーとノッチの配置をご覧ください。

補足： わらしの横の小さなドットは、アクティビティの記録がオンであることを示します。

うまくいかないときは

  • わらしが見えない： ノッチの裏に隠れている可能性があります。トラブルシューティングをご覧ください。
  • 測定値に「利用不可」と表示される： そのMacではmacOSがその測定値を提供していません。Warashiが値を推測することはありません。

詳しくはトラブルシューティングをご覧いただくか、adam@warashi.appまでメールでお問い合わせください。
