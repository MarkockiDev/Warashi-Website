システムヘルパー

オプションのシステムヘルパーをインストールすると、WindowServerなどのシステムプロセスを含めたり、80%未満の充電上限を設定したり、蓋を閉じたままMacをスリープさせないようにしたりできます。

ふつうのアプリより少しだけ多くのアクセスが必要なこともあります。オプションのシステムヘルパーは、そのうちちょうど3つだけを担い、それ以外は何もしません：

  • システムプロセス： WindowServer、kernel_task、mdsなどを、アプリ、負荷の高いアプリ、履歴に表示。
  • 80%未満の充電上限（バッテリーと充電上限）。
  • 蓋を閉じたままスリープさせない（スリープさせない）。
  1. 設定 › システムを開く

    ⌘,を押してシステムを選びます。ヘルパーが必要な機能を初めて選んだときにも、Warashiがオンにするを表示します。

  2. 「システムプロセスを表示」をオンにする

    Warashiが小さなヘルパーをインストールします。その後、macOSが承認を求めます。

  3. システム設定で許可する

    Warashiでログイン項目の設定を開くをクリックするか、システム設定 › 一般 › ログイン項目と機能拡張を開きます。バックグラウンドでの実行を許可の下でWarashiをオンにします。macOSがパスワードを求めることがあります。

ヘルパーにできることとできないこと

  • プロセスのカウンタを読み取ります：CPU時間、メモリ、ディスク、エネルギー。
  • 頼まれたときだけ、ヘルパー自身が確認したうえで20%〜75%の充電レベルをひとつ設定するか、3分間の期限つきで蓋を閉じたままMacをスリープさせないようにします。Warashiが期限の更新をやめると、ヘルパーが自分で終了します。
  • ほかのコマンド、パス、引数は一切受け付けず、Warashiにしか応答しません（双方がお互いの署名を確認します）。
  • スイッチをオフにすると削除されます。

うまくいかないときは

  • それでもシステムプロセスが表示されない： システム設定 › 一般 › ログイン項目と機能拡張 › バックグラウンドでの実行を許可でWarashiがオンになっていることを確認し、スイッチをオフにしてからもう一度オンにしてください。
