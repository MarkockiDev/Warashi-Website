Claude Code、Codex、Cursor を使っている場合、Warashi が見守ります。各セッションが何をしているか、それぞれが使用上限にどれだけ近いか、いつあなたの対応が必要かを表示します。オンにするまではオフです。

  1. オンにする

    設定 › コーディングエージェントを開いてClaude Code、Codex、Cursor を見守るをオンにするか、アプリ › デベロッパ上部のコーディングエージェントのカードでオンにする…を押します。Warashi は、通知を送ってよいかを一度だけたずねます。

  2. 通知する内容を選ぶ

    エージェントが返答を待っているときに知らせる（権限や回答を求めて止まったとき）、エージェントが完了したときに知らせる（1分以上作業したあと）、使用上限が近づいたら警告する（80%と95%）。いずれも通知として届き、ノッチが開きます。上限の場合は数秒間、それ以外はエージェントのアプリに戻るまで開いたままです。通知をクリックすると、エージェントの一覧が表示されます。

  3. 作業の様子を見守る

    アプリ › デベロッパのコーディングエージェントカードには、各セッションの状態（作業中、あなたを待っている、完了）とプロジェクトが表示されます。エージェントが作業している間は、ノッチの横に経過時間が表示され、返答を待っているエージェントが優先されます。設定 › カスタマイズでメニューバーウインドウにコーディングエージェントを追加すると、上限もそこで確認できます。メニューバーでは、わらしの横にコーディングエージェントの上限を選べます。

使用上限

上限はそれぞれリングで表示されます。5時間上限と週間上限、そしてリセット時刻です。リングは80%から琥珀色、95%から赤になります。

  • Codex は上限をMac上の自身のファイルに書き込むため、Codex が次に応答したあとに表示されます。
  • Cursor は月ごとの使用量を表示します。Cursor の使用量を表示をオンにすると、Warashi は Cursor のコマンドラインエージェントがキーチェーンに保存しているサインインを使って Cursor に問い合わせます。先に cursor-agent login で一度サインインしてください。macOS からたずねられたら、常に許可を選びます。
  • Claude Code は使用上限を Mac に保存しません。Claude の使用上限を表示 をオンにすると、Claude Code の実行中、Warashi は数分ごとにキーチェーンにある Claude Code のサインイン情報を使って Anthropic に問い合わせます。オンにしたときに macOS が一度だけ読み取りの許可を求めるので、常に許可 を選んでください。Warashi が自分から尋ねることはありません。あとで macOS の許可が必要になったときは、設定にその旨と 許可… ボタンが表示されます。サインイン情報はこの問い合わせにのみ使われ、保存・変更・他所への送信はされません。

Claude にサインインする

Claude の使用上限を表示の下に、Claude Code にサインインしているアカウントが設定に表示されます。サインインしていない場合は、サインインを押すとターミナルで Claude Code 自身のサインインが開き、ブラウザに移動します。Claude Code はサインインを、使っている間しか更新しないため、静かな日が続くと上限が更新されなくなることがあります。サインインを自動で更新をオンにすると、Warashi は6時間に1回までのペースで、Claude Code に最小モデルからの短い返答を1つ求め、Claude Code がサインインを更新します。今すぐ更新を押すとすぐに実行します。Warashi がサインインを自分で更新したり書き込んだりすることはありません。

作業中はスリープさせない

設定 › コーディングエージェント でエージェントの作業中は Mac をスリープさせないをオンにするか、スリープさせないの自動 › コーディングエージェントの作業中をオンにします。エージェントが作業中または返答を待っている間と、その後3分間は、Mac がスリープしません。蓋を閉じてもスリープしないをオンにすると、充電器につないだ MacBook は蓋を閉じても作業を続けます。

フライトログで

2分を超える作業は、フライトログに記録されます：「Claude Code が shop で1時間12分作業しました」。

知っておきたいこと： Warashi は、エージェント自身のファイルから各セッションの状態と上限だけを読み取ります。コードやプロンプト、会話は読みません。表示されるのはプロジェクトフォルダの名前だけです。分析データにも、これらは含まれません。

うまくいかないときは

  • Claude の上限に、サインインの期限が切れたと表示される： ターミナルで一度 Claude Code を実行すると、サインインが更新されます。Claude デスクトップアプリ内の Claude Code は、サインインを別の場所に保存しています。
  • Codex の上限が表示されない： Codex が次に応答したあと、直近1週間のセッションから表示されます。
  • Cursor は、あなたの対応が必要なことを伝えません： Cursor はWarashiが読み取れる場所にその情報を記録しないため、作業中と完了だけが表示されます。完了は、停止してから約1分後です。
  • ほかのエージェント： Gemini CLI、Aider などは、作業中や待機中の状態は出ませんが、CPUとメモリがデベロッパに表示されます。
